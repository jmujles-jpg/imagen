## Regla de tolerancia por llegada tarde (con turnos)

El servicio que se hace depende de cuánto tarde llegue la clienta.

- Ejemplo: si tenía turno para **soft gel** y llega **15 minutos tarde**, no se le hace el soft gel. Se le hace otro servicio que lleve menos trabajo y menos tiempo.
